# Segmentación de Pozos Petroleros mediante Clustering

Este proyecto implementa un dashboard interactivo en **Streamlit** para:

- Cargar datos de pozos petroleros
- Escalarlos y preprocesarlos
- Aplicar PCA
- Segmentar mediante K-Means
- Visualizar clusters en PCA 3D
- Ver centroides y métricas
- Analizar registros individuales

## Cómo ejecutar en Streamlit Cloud

1. Subir este repositorio a GitHub
2. Entrar a https://share.streamlit.io
3. Seleccionar "New App"
4. Elegir este repositorio
5. Archivo principal: `app.py`

El dashboard se desplegará con una URL pública.
